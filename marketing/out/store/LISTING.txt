PRIVACY PRACTICES TAB  (read by Google's reviewer only, never shown to users)

Single purpose
Shows a novelty sale banner over the right-hand 30% of web pages on Black Friday only. It does nothing on any other day.

Host permission justification (content script on all URLs)
The extension is a Black Friday joke: on that one day it shows a "30% OFF" banner over the right-hand 30% of every web page, so its content script must be able to load on all HTTP/HTTPS pages. On every other day the script checks the date and does nothing. It collects no data, makes no network requests, and does not read or change page content; it only adds its own overlay element, which the user can hide with the toolbar button.

(This version asks for no other permissions, so the activeTab and scripting boxes disappear
once the new package is uploaded.)

Remote code            No, I am not using remote code.

TEST INSTRUCTIONS TAB  (reviewer only)
This extension is deliberately inactive except on Black Friday. To see it work, set the computer's date to Friday 27 November 2026 and open or reload any https page: a sale banner covers the right-hand 30% of the page. On that date, clicking the toolbar button hides the banner on the current tab and clicking again brings it back. On any other date nothing is shown and the toolbar button does nothing. No account needed.
